Online Examination System

Project Description

The Online Examination System is a Java-based desktop application developed using Java Swing. It allows students to enter their name and attend a multiple-choice examination. After completing the examination, students can view their final score.

Features

- Student name entry through a login screen.
- Multiple-choice questions with four options.
- Previous and Next navigation between questions.
- 60-second countdown timer.
- Automatic submission when the timer expires.
- Score calculation based on correct answers.
- Result display with student name and score.
- Resizable examination window.

Technologies Used

- Java
- Java Swing
- AWT

How to Run

1. Clone or download this repository.
2. Open the project in any Java IDE.
3. Compile the Java files.
4. Run "LoginFrame.java".
5. Enter your name and click Login.
6. Attend the examination and submit your answers.
7. View your examination result.

Learning Outcomes

- Understanding Java Swing components.
- Working with event handling.
- Using layout managers.
- Implementing arrays and conditional statements.
- Implementing countdown timers.
- Creating multiple frames in Java.
