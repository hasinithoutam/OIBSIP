Number Guessing Game 

About the Project

The Number Guessing Game is a Java-based GUI application developed using Java Swing. It allows users to play a number guessing game by selecting different difficulty levels and guessing a randomly generated number.

Features

- Three difficulty levels: Easy, Medium, and Hard.
- Random number generation.
- Interactive graphical user interface.
- Tracks the number of rounds played.
- Maintains wins and losses.
- Displays game history.
- User-friendly interface.

Technologies Used

- Java
- Java Swing
- AWT
- Java Collections (ArrayList)
- Random Class

Concepts Used

- Object-Oriented Programming
- Event Handling
- GUI Development
- Random Number Generation
- ArrayList

How to Run

1. Install Java JDK on your system.
2. Open the project in any Java IDE, such as VS Code or Eclipse.
3. Compile and run the main Java file.
4. Select your preferred difficulty level.
5. Start guessing the number and enjoy the game!

Project Purpose

This project was developed to improve practical knowledge of Java programming, GUI development, event handling, and object-oriented programming.
